# Data attribution

The bank in `src/data/generated/facts_wikidata.json` derives from Wikidata structured data, distributed under [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing). Properties: P1082 population, P2046 area, P2044 elevation, P2043 length, P569 birth date.

Threshold records retain QIDs/properties in `meta`; history comparison IDs contain both QIDs. Inspect each entity at `https://www.wikidata.org/wiki/<QID>`. Generated prompts and application code are MIT licensed. A dated snapshot does not guarantee current or independently verified facts.
